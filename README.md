# EasyBusyChat для 1С / BAS

Інтеграція 1С / BAS із сервісом Easy-Busy Chats: синхронізація чатів та акаунтів, зв'язки з об'єктами бази, надсилання повідомлень і друкованих форм, окреме вікно вебчату у Windows.

| Частина | Версія джерел | Призначення |
|---|---|---|
| `extensions/EasyBusyChat` | 0.8.3 | Розширення для BAS Малий бізнес із контакт-центром |
| `extensions/EasyBusyChatUniversal` | 0.8.3 | Базова інтеграція для конфігурацій із БСП |
| `component` | 0.6.1 | Native API DLL та вбудований процес Rust/Tauri/WebView2 |

- [Встановлення та налаштування](docs/installation.md)
- [Складання та перевірки](docs/build.md)
- [API зовнішньої компоненти](docs/component-api.md)
- [Зміни](CHANGELOG.md)

Джерела містять необхідні бінарні макети розширень. Готові CFE/DLL є артефактами випуску; каталог `.local/` призначений для локальних збірок і не входить до Git. Версія у джерелах сама по собі не означає публікацію відповідного релізу.

Перед встановленням перевірте сумісність на копії своєї інформаційної бази. Окреме вікно чату потребує Windows-клієнта 1С / BAS та WebView2 Runtime.
