# Встановлення

`EasyBusyChat` призначене для BAS Малий бізнес 1.6/2.0 та додає контакт-центр. `EasyBusyChatUniversal` містить базову інтеграцію; цільові конфігурації також включають BAS Управління торгівлею 3.5, КУП 3.5 та ERP 2.5. Це перелік призначення, а не підтвердження тестування кожної редакції.

Вимоги попередньої поставки: платформа від 8.3.19.1529 і БСП від 3.1. Фактичну застосовність визначає ваша конфігурація. Режими сумісності записані в `Configuration.xml` відповідного розширення. Для окремого вікна чату потрібні Windows, тонкий або товстий клієнт та Microsoft Edge WebView2 Runtime. DLL x86/x64 входять у розширення; окремий Visual C++ Redistributable для компоненти зі статичним CRT не потрібен.

1. Створіть резервну копію бази. Спочатку встановіть розширення у тестову копію під адміністратором.
2. Відкрийте «Функції для технічного спеціаліста» → «Управління розширеннями конфігурації» та додайте CFE відповідного варіанта.
3. Для довіреної поставки налаштуйте дозвіл на використання зовнішньої Native API-компоненти. У конфігураціях із відповідними прапорцями це потребує вимкнення «Безпечного режиму» та «Захисту від небезпечних дій» саме для цього розширення.
4. Перезапустіть клієнт. Відкрийте Easy-Busy Chat → Адміністрування → Налаштування, введіть токен свого сервісу та виконайте початкове заповнення.
5. Призначте користувачам необхідні ролі, перевірте синхронізацію компаній/акаунтів/чатів і відкриття чату. Перевірку надсилання виконуйте лише на погодженому тестовому діалозі.

Токени зберігайте у налаштуваннях інформаційної бази, не в коді або журналах. Потрібен HTTPS-доступ до `api.easy-busy.cloud` і вебресурсів сервісу. Вебклієнт та клієнти Linux/macOS не завантажують Windows DLL; можливості без окремого вікна чату залежать від базової конфігурації.

Якщо DLL не підключається, перевірте архітектуру клієнта, дозволи розширення, WebView2 та журнал реєстрації. Якщо початкове заповнення не працює, перевірте токен, права компанії та мережевий доступ. Діагностичні журнали компоненти вмикаються явно через її API.
