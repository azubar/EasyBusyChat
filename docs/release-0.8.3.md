# Розширення 0.8.3 / компонента 0.6.1

Випуск містить `EasyBusyChat_v0.8.3.cfe` для BAS Малий бізнес із контакт-центром та `EasyBusyChatUniversal_v0.8.3.cfe` для базової інтеграції. Обидва варіанти містять Native API DLL для Windows x86/x64 і компоненту SpreadSheet 0.6.5.

Компонента 0.6.1 розділяє профілі WebView2 за контекстом авторизації. Стандартне складання використовує статичний CRT, HTTPS origin, iframe analytics/YouTube та увімкнені DevTools. Джерела розширень і компоненти об'єднані в одному репозиторії з автономними засобами складання.

CFE повторно зібрані платформою 8.3.27.2130 на одній тестовій BAS: виконано CheckConfig, перевірку застосовності та зворотне вивантаження. Зіставлено 47 непорожніх BSL-модулів повного варіанта, 46 Universal та всі бінарні макети. Це не підтвердження сумісності з кожною редакцією BAS.

До файлів випуску додаються `manifest.json`, `SHA256SUMS.txt`, `LICENSE.txt` і `THIRD_PARTY_NOTICES.txt`. Окремі `EasyBusyChat_x86.dll` / `EasyBusyChat_x64.dll` — ті самі перевірені вкладені файли з CFE, а не debug-збірки. Для встановлення розширення завантажувати їх окремо не потрібно.

Перед оновленням створіть резервну копію й перевірте випуск на копії своєї бази. Окреме вікно чату потребує Windows-клієнта та WebView2 Runtime. Див. [встановлення](installation.md), [складання](build.md), [сторонні ліцензії](../THIRD_PARTY.md).
